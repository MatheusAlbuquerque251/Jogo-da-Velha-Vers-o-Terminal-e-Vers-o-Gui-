# 🎮 Jogo da Velha em Python

Duas versões do clássico Jogo da Velha: uma jogada direto no **terminal** e outra com **interface gráfica em Tkinter**, com tema escuro e janela de resultado personalizada.

## 💻 Versão Terminal
Jogo para dois jogadores, com o tabuleiro desenhado em texto e as jogadas feitas por linha e coluna.

## 🖱️ Versão Tkinter
Evolução do jogo com botões clicáveis, indicador de vez, aviso de posição ocupada e popup de fim de jogo no mesmo estilo da janela principal.
